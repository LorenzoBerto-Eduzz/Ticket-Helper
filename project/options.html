Como atualizar:

  1. Clique no botão acima para baixar a pasta compactada.
  2. Mova o conteúdo (pasta com mesmo nome) para o local da extensão em uso.
  3. Realize a reposição da pasta da extensão antiga pela baixada.
  4. Recarregue a extensão em chrome://extensions.
  5. Recarregue as abas de ticket/chat em uso.

Avisos de Produtores

Privacidade

Dados de tickets e clientes ficam apenas no armazenamento temporário de sessão do navegador. Os avisos de produtores escritos pelo usuário ficam salvos no armazenamento local deste perfil do Chrome entre sessões. Para apagar um aviso, limpe o nome do produtor. Um texto de aviso vazio mantém o produtor na lista.
